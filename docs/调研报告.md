# 简历制作工具调研报告

> 调研对象：[小林简历](https://jianli.xiaolinnote.com/)（[模板库](https://jianli.xiaolinnote.com/templates)）
> 定位：面向技术从业者的免费在线简历工具，核心链路「选模板 → 在线编辑 → 实时预览 → 导出 PDF」。

## 一、核心功能拆解

| 功能模块 | 具体功能 |
| --- | --- |
| 模板中心 | 22+ 模板，按场景（校招/社招）与岗位（后端/前端/测试/嵌入式/大模型算法等）分类；一键套用，内置示例内容引导填写 |
| 内容编辑 | 模块化编辑：基本信息、教育背景、专业技能、工作/项目经历、自我评价等；富文本（加粗、列表）；头像上传 |
| 样式定制* | 字体族与字号调节、主题色切换、行距/页边距设置、模块显隐与排序 |
| 实时预览 | 所见即所得，编辑即渲染，A4 分页效果预览 |
| 导出 | 一键导出高质量 PDF，还原排版效果 |
| 数据存储 | 云端自动保存、加密存储，登录后可跨设备继续编辑 |

\* 样式定制为同类成熟编辑器的通用能力（官网未逐项列出），建议本项目实现。

## 二、实现思路参考

1. **数据驱动渲染**：简历 = 一份 JSON（基本信息 + 模块数组 + 样式配置）；模板只是纯渲染组件。内容与样式分离，换模板不丢数据。
2. **模块顺序可配置**：不同模板预设不同模块顺序（校招教育前置、社招技能前置），用户可自定义增删与排序。
3. **PDF 导出**：首选浏览器打印方案（print CSS + `@page` A4），文字可选中、清晰度高；`html2canvas + jsPDF` 作兜底。
4. **存储策略**：MVP 用 localStorage 自动保存 + JSON 导入/导出；云端同步放后期。
5. **技术栈建议**：Vue3/React + TypeScript + TailwindCSS，纯前端实现，零后端成本即可上线。

## 三、本项目（ResumeMake）MVP 建议

| 优先级 | 范围 |
| --- | --- |
| P0 | 3~5 套模板；模块化内容编辑；字号/主题色/边距调节；实时 A4 预览；PDF 导出；本地自动保存 |
| P1 | 模块拖拽排序与显隐；JSON 导入/导出；头像裁剪；扩充模板库 |
| P2 | 账号与云端同步；AI 内容润色；多语言简历 |
