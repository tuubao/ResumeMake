# 模板库说明（重设计）

> 依据：[产品设计文档](./产品设计文档.md)｜参考基准：小林简历模板中心（https://jianli.xiaolinnote.com/templates）
> 原则：既有功能全部保持不变，仅对模板层做扩充与重设计。

## 1. 重设计目标

原模板库仅 3 套单栏模板、共用一份较简略的示例简历。对标成熟简历产品的模板中心，本次重设计解决两个问题：

1. **模板数量偏少** → 扩充至 **12 套场景模板**，新增 4 类视觉版式
2. **示例内容不够完整** → 每套模板自带**完整场景示例**，默认示例同步升级为完整校招简历

## 2. 成熟度标准（来自参考基准）

- **场景化**：模板按「岗位 × 求职阶段」组织（校招 / 社招 × Java / 前端 / AI 算法 / 测开 / Go / C++ / 运营等），附岗位标签与场景化描述
- **内容完整**：示例覆盖该场景的全部核心模块——校招含教育（GPA / 排名 / 奖学金 / 英语）、技能、实习、项目、自评；社招含深度技能、多段履历、重点项目；算法岗含科研论文
- **量化表达**：成果一律量化（响应 300ms→50ms、吞吐提升 5 倍、一致性 99.99%…），关键指标加粗
- **结构化项目段落**：项目简介 / 技术栈 / 个人职责 / 技术亮点（或工作成果 / 项目成果）分段呈现，职责与成果拆分
- **叙事顺序**：校招教育前置，社招「技能-履历-项目」黄金三段式

## 4. 使用方式（模板中心）

- **使用此模板**：仅切换模板外观（`templateId`），用户内容不动——与原有行为一致
- **使用示例内容**：弹窗确认后载入该模板的完整场景示例并进入编辑器；取消则不做任何改动
- 缩略图使用各模板自带示例渲染，所见即所得；分类筛选（全部 / 校招 / 社招 / 通用）保持原有行为
- 编辑器内切换模板、样式定制、字段级字体覆盖、三格式导出（PDF / JPG / Word）等全部既有功能不受影响

## 5. 架构约定（保持数据与模板分离）

- 模板仍是纯渲染组件，只消费 `Resume` JSON；新视觉同样支持全部样式配置（字体 / 字号 / 主题色 / 行距 / 页边距）、字段级 `TextStyle` 覆盖、头像、自定义信息、项目链接与富文本
- `TemplateMeta` 增加 `tags`（岗位标签）与 `sample`（场景示例工厂）两个元数据字段；示例数据集中在 `src/data/samples.ts`
- 双栏版式按模块类型分栏渲染（侧栏：技能 / 教育 / 自评；主栏：工作 / 项目 / 自定义），**全部模块均渲染、数据不改写**
- `ModuleSection` 增量新增 `chip` / `dot` 标题变体与模块类型 class；`ResumeHeader` 增量新增 `align` 属性（默认居中），旧模板渲染行为不变
- 示例中的「实习经历」「科研论文」分别复用 `work` / `custom` 模块类型（标题自拟），不新增数据类型，旧存档兼容逻辑不变

## 6. 测试覆盖

- 单测：示例数据合法性 / 完整性 / id 唯一性（`samples.spec`）、12 套模板逐一套示例渲染与新视觉专项（`templates.spec`）、模板中心交互（`gallery.spec`）、`applyResume`（`store.spec`）
- E2E：12 套模板与标签展示、使用示例内容（接受 / 取消确认）、新视觉预览渲染，以及既有核心链路 / 导出 / 样式回归
