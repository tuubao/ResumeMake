# ResumeMake 开发计划

> 范围：MVP（P0）｜依据：[产品设计文档](./产品设计文档.md) ｜ 估算：约 7 人日

## 1. 技术选型

| 项 | 选择 | 说明 |
| --- | --- | --- |
| 框架 | Vue 3 + TypeScript + Vite | 生态成熟，模板即组件，开发效率高 |
| 样式 | TailwindCSS | 快速实现年轻化 UI |
| 状态 | Pinia | 简历数据 + 样式配置单一数据源 |
| 路由 | Vue Router | 模板选择页 / 编辑器页 |
| 测试 | Vitest + Vue Test Utils；Playwright（核心链路 E2E） | 对应 AGENTS.md 测试要求 |
| PDF | 浏览器打印（print CSS + `@page` A4） | 文字可选中，零依赖 |
| 存储 | localStorage（防抖自动保存） | 纯前端，无后端 |

## 2. 核心数据契约

```ts
interface Resume {
  templateId: string
  basics: { name; phone; email; jobTitle; avatar?; extra? }
  modules: Array<{ id; type: 'education'|'skills'|'work'|'projects'|'selfEvaluation'; title; items: any[] }>
  style: { fontFamily; fontSize; themeColor; lineHeight; pageMargin }
}
```

模板是纯渲染组件，只消费 `Resume`；切换模板仅改 `templateId`，数据不动。

## 3. 里程碑与任务拆分

| 里程碑 | 任务 | 交付物 / 测试 | 估算 |
| --- | --- | --- | --- |
| M1 骨架 | Vite 初始化、Tailwind/Router/Pinia/Vitest 接入、基础布局 | 可运行空应用，测试脚本跑通 | 0.5 天 |
| M2 数据层 | Resume 类型与 store、示例数据、localStorage 自动保存/恢复 | store 单测：模块增删改、保存恢复、数据校验 | 1 天 |
| M3 模板渲染 | 3 套单栏模板（不同配色与模块顺序）、A4 分页预览组件 | 模板渲染快照测试 | 1.5 天 |
| M4 编辑器 | 模块化表单、富文本（仅加粗/列表）、头像上传、样式面板（字体/字号/主题色/行距/边距） | 表单绑定与样式应用单测 | 2 天 |
| M5 模板页与导出 | 模板缩略图与筛选、一键套用、print CSS 导出 PDF | E2E：换模板不丢数据；打印样式验证 | 1 天 |
| M6 打磨验收 | UI 年轻化打磨、超长内容分页等边界处理、README、全量测试 | 全部测试通过 + 手动验收 | 1 天 |

每个里程碑完成即提交 commit（`feat/test/fix/docs` 前缀），可独立回滚。

## 4. 测试与验收标准

- 每个功能点配套 Vitest 单测；核心链路「编辑 → 预览 → 保存 → 换模板 → 导出」有 E2E 覆盖
- 交付门槛：`npm test` 全绿；手动验证 A4 打印效果（文字可选中、分页不截断、样式还原）
- 单测运行：`npx vitest run <file>`；E2E：`npx playwright test`

## 5. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 内容超长导致分页截断 | `break-inside: avoid` 等分页规则 + 超长提示 |
| 浏览器打印差异 | 以 Chrome/Edge 为基准，README 注明 |
| 富文本范围膨胀 | MVP 只做加粗/列表，不引入重型编辑器 |
