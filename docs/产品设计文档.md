# ResumeMake 产品设计文档

> 版本：v0.1（MVP 方向稿）｜依据：[调研报告](./调研报告.md)

## 1. 产品概述

- **定位**：免费、纯前端的在线简历制作工具
- **目标用户**：求职者，以技术岗为主，兼顾校招与社招场景
- **核心价值**：选模板 → 填内容 → 调样式 → 导出 PDF，十分钟内产出一份专业简历
- **产品原则**：所见即所得；数据与模板分离（换模板不丢内容）；数据存本地，天然隐私安全

## 2. 整体方向

- MVP 为纯前端单页应用（Vue3/React + TypeScript + TailwindCSS，开发时定其一），零后端即可上线
- 简历内容抽象为一份 JSON（基本信息 + 模块数组 + 样式配置），模板是纯渲染组件
- 先跑通核心闭环，其余功能按 P1/P2 迭代

## 3. 主要功能（MVP）

| 功能 | 说明 |
| --- | --- |
| 模板中心 | 首批 3~5 套模板，预设模块顺序（校招教育前置/社招技能前置），一键套用，内置示例内容 |
| 内容编辑 | 模块化表单：基本信息、教育背景、专业技能、工作/项目经历、自我评价；支持加粗、列表；头像上传 |
| 样式定制 | 字体与字号调节、主题色切换、行距与页边距设置 |
| 实时预览 | 编辑即渲染，A4 分页所见即所得 |
| PDF 导出 | 浏览器打印方案（print CSS + @page A4），文字可选中、排版高保真 |
| 自动保存 | localStorage 实时保存，刷新/重开不丢数据 |

## 4. 页面结构

- **模板选择页**：模板缩略图 + 分类筛选 + 一键使用
- **编辑器页**：左侧编辑面板 ｜ 右侧 A4 实时预览 ｜ 顶部工具栏（切换模板、样式设置、导出 PDF）

## 5. 后续迭代

- **P1**：模块拖拽排序与显隐、JSON 导入/导出、头像裁剪、扩充模板库
- **P2**：账号与云端同步、AI 内容润色、多语言简历
